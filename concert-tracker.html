💡 How Discovery Works

What gets searched: The app queries Bandsintown, Ticketmaster, and JamBase for each artist in your list, filtering to shows within ~60 miles of San Francisco.

Best coverage for: Touring artists, regional acts, jazz artists who list shows on Bandsintown (most do). Big venues like SFJazz, Yoshi's, The Fillmore, The Great American Music Hall, and The Independent are all covered.

May not catch: Last-minute local bookings, shows only announced on social media, truly underground gigs. Add those manually with the "Add Show" button.

🔗 Connect Your Google Sheet (Apps Script)

✅ One-time setup, about 5 minutes. No API keys, no OAuth, no passwords. Your sheet stays private.
Step 1 — Open the Apps Script editor
Open "Music (Live Shows)" in Google Sheets.
Click Extensions → Apps Script. A new tab opens with a code editor.
Step 2 — Paste this script
Delete everything in the editor, then paste exactly this: 
function doGet(e) {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('2026');
  const cb = (e && e.parameter && e.parameter.callback) || 'concertTrackerCallback';

  if (e && e.parameter && e.parameter.action === 'append') {
    try {
      const show = JSON.parse(e.parameter.data);
      const d = show.date ? new Date(show.date + 'T12:00:00') : null;
      const day = d ? ['Sun','Mon','Tue','Wed','Thu','Fri','Sat'][d.getDay()] : '';
      const ds = [show.doors, show.showTime].filter(Boolean).join(' / ');
      const tix = {y:'y',comp:'guest',door:'free',awaiting:'awaiting'}[show.tixStatus] || 'n';
      sheet.appendRow([show.date||'', day, show.artist||'', show.venue||'',
                       ds, tix, show.who||'', show.tixLoc||'', show.notes||'']);
      return ContentService.createTextOutput(cb + '({"ok":true})')
        .setMimeType(ContentService.MimeType.JAVASCRIPT);
    } catch(err) {
      return ContentService.createTextOutput(cb + '({"ok":false})')
        .setMimeType(ContentService.MimeType.JAVASCRIPT);
    }
  }

  const [headers, ...rows] = sheet.getDataRange().getDisplayValues();
  const shows = rows.map(r =>
    Object.fromEntries(headers.map((h, i) => [h, r[i]]))
  );
  return ContentService
    .createTextOutput(cb + '(' + JSON.stringify(shows) + ')')
    .setMimeType(ContentService.MimeType.JAVASCRIPT);
}
✨ This script handles both sync and pushing shows you add from the Discover tab directly to your sheet.
Step 3 — Deploy as a web app
Click Deploy → New deployment.
Click the gear icon ⚙️ next to "Select type" and choose Web app.
Set Execute as: Me.
Set Who has access: Anyone.
Click Deploy → authorize when prompted → click Deploy again.
Step 4 — Copy the Web App URL
After deploying, Google shows a Web app URL starting with
https://script.google.com/macros/s/…/exec
Copy that URL. Close this window, open ⚙️ Settings, paste it into the URL field, and hit Save. Then click 🔄 Sync Sheet.
💡 Updating the script later: If you change the script, go to Deploy → Manage deployments → edit the existing deployment (don't create a new one) — that keeps the same URL.
How it works: The script reads your 2026 tab and returns the data when the app asks for it. Your spreadsheet stays completely private — the script only shares what it reads, and only this app calls it.
